# Datasets

Dataset directories contain input pairs, preparation stages, and the custom
schema metadata required by the augmentation algorithm. Generated files do not
belong here; they are kept in [`results/`](../results/).

- [`censobench/`](censobench/README.md): temporal Brazilian School Census queries.
- [`atlas_sql_br/`](atlas_sql_br/README.md): geospatial AtlasSQL-BR queries.

Consult each dataset guide for its format and provenance. The repository's MIT
license does not relicense third-party data.
